
# Westlake Student Portal

## 1. Project Description

Westlake Student Portal is a web-based student management interface designed to provide students with easy access to student information, course details and dashboard summaries.

The system provides a simple and user-friendly interface with responsive navigation and interactive features.

## 2. Project Objectives

- To develop a responsive student portal interface.
- To provide easy access to student and course information.
- To display student-related summaries through data visualisation.
- To provide simulated login and registration functions.

## 3. System Features

- **Homepage:** Displays the portal introduction and navigation.
- **Login:** Allows users to log in using demo credentials.
- **Registration:** Allows users to register a student account.
- **Dashboard:** Displays summary cards and a student department chart.
- **Students:** Displays student records in a table.
- **Courses:** Displays course information in a table.
- **Dark Mode:** Allows users to switch between dark and light themes.
